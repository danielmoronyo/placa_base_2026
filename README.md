# Placas base AM4 (B550) — Test Interactivo de Componentes

Aplicación web interactiva (HTML5 + CSS3 + JavaScript vanilla sin dependencias externas) para aprendizaje y evaluación técnica de componentes de hardware.

Permite identificar y arrastrar las etiquetas a los componentes clave en 4 placas base AM4 con chipset AMD B550 de PcComponentes:

1. **MSI MPG B550 GAMING PLUS (ATX)**:
   - Formato ATX completo con disipador VRM extendido sobre el panel trasero con acento rojo y emblema MPG.
   - Disipador de ranura M.2 Shield Frozr de aluminio cepillado.
   - Ranura principal PCIe 4.0 x16 reforzada con Steel Armor inoxidable.
   - Panel trasero premontado con puertos USB 3.2 Gen2 (rojo), Type-C, HDMI, DisplayPort, botón Flash BIOS y audio óptico S/PDIF.
   - Códec de audio Audio Boost con circuito aislado y condensadores japoneses dorados.

2. **ASUS PRIME B550M-A WIFI II (Micro-ATX)**:
   - Formato Micro-ATX (cuadrado 1:1) con el característico serigrafiado geométrico blanco/plateado ASUS Prime Cyber-Lines.
   - Módulo Wi-Fi 6 integrado con doble conector de antena dorado SMA en el panel trasero.
   - Disipador de aluminio plateado en el VRM izquierdo con aletas de refrigeración verticales y fases superiores descubiertas.
   - Ranuras DDR4 con colores alternos característicos de ASUS (negro y gris) y trabas unificadas Q-DIMM.
   - Ranura PCIe 4.0 x16 con blindaje metálico SafeSlot Core.
   - Disipador circular de chipset B550 con logo PRIME.

3. **Gigabyte B550M Aorus Elite (Micro-ATX)**:
   - Diseño gaming Aorus con PCB negro mate y líneas de serigrafía cibernética naranja y gris.
   - Disipador VRM angular con bisel plateado y el emblemático logotipo Aorus Falcon.
   - Ranura PCIe 4.0 x16 con protección Ultra Durable PCIe Armor envolvente.
   - Botón físico Q-Flash Plus en la placa base para actualización de BIOS sin CPU.
   - Disipador de chipset B550 angular con logotipo Aorus.
   - Línea de aislamiento de audio Audio Noise Guard con condensadores de audio de alta gama.

4. **ASRock B550M Pro4 (Micro-ATX)**:
   - PCB "Sapphire Black" con franjas diagonales de competición blancas.
   - Disipadores dobles XXL de aleación de aluminio pulido en VRM izquierdo y superior.
   - Disipador M.2 Armor de aluminio sobre la ranura principal Hyper M.2 PCIe 4.0.
   - Ranura PCIe 4.0 x16 con ASRock Steel Slot.
   - Cabezal interno USB 3.0 con carcasa azul y conectores de condensadores de audio ELNA.

Cada placa incluye 14 componentes evaluados (100 puntos por placa) con cálculo automático del promedio y nivel de calificación final.

## Uso
Abre `index.html` en cualquier navegador moderno (doble clic o servidor web local como GitHub Pages).

## Características
- Gráficos vectoriales SVG de alta definición generados proceduralmente con gradientes metálicos, sombreado y texturas fotorrealistas.
- Compatible con ratón y pantallas táctiles (Pointer Events).
- Sistema de audio estéreo Web Audio API con respuesta acústica inmediata al acertar.
- Escenario escalable automáticamente a cualquier resolución de ventana.
